# ymc-replacements

Дополнительные замены треков для мода `ru.yandex.music.unc`, когда нужного
трека нет в [FckCensorData](https://github.com/Hazzz895/FckCensorData).

## Как добавить трек

1. Положите аудиофайл в `tracks/<id>` **без расширения**, где `<id>` — id трека
   Яндекс.Музыки (например, `tracks/145054524`).
2. Добавьте запись в массив `tracks` в `manifest.json` (пример ниже).
3. Закоммитьте и запушьте в ветку `main`.

Мод скачивает манифест при старте приложения, кэширует его в
`ymc_manifest.json` и обновляет в фоне. Пересобирать APK при добавлении
трека **не нужно** — достаточно обновить репозиторий и перезапустить приложение.

## Поля манифеста

```json
{
  "tracks": [
    {
      "id": "123456789",
      "title": "Настоящее название",
      "cover": "avatars.yandex.net/get-music-content/.../%%",
      "artist": "Исполнитель",
      "artist_id": "4952161",
      "file": "123456789",
      "repair": true,
      "play_id": "987654321"
    }
  ]
}
```

- `id` — обязательно, id трека;
- `title` — настоящее название (иначе остаётся название от Яндекса);
- `cover` — путь обложки в формате Яндекса (`.../%%`) или полный URL;
- `artist` + `artist_id` — исполнитель в очереди/мини-плеере и на странице артиста;
- `file` — имя файла в `tracks/`, по умолчанию равно `id`;
- `repair: true` — применить тот же фикс MP4 (`trex`/`sidx`), что и к файлам
  FckCensor; нужен, если файл собран в таком же формате;
- `play_id` — только для треков, удалённых из каталога Яндекса (нужен stand-in id).

## Формат аудио

Предпочтительно сегментированный MP4/DASH, как у FckCensor: файл без
расширения, `moov` в начале, дальше `moof`/`mdat` сегменты. Обычный MP4
или MP3 теоретически играется напрямую по http, но гарантии нет — проверяйте
на устройстве.
